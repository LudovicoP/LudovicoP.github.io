Two courseworks for MATH70099 Big Data: Statistical Scalability with PySpark, MSc in Statistics at Imperial College London. CW1 analyses the "Big Data paradox" in survey estimation — how massive opt-in surveys can remain substantially biased despite small nominal sampling error — and implements Poisson matrix factorisation using Hadoop Streaming with custom mapper/reducer scripts. CW2 extends the work to further scalable statistical learning methods.

## Methods

- Data defect correlation and survey bias decomposition
- Poisson matrix factorisation (coordinate ascent)
- Hadoop Streaming: custom mapper and reducer in Python
- Statistical Query Model analysis
- PySpark for distributed statistical computation
